# 卡坦岛复现版

## 启动

```bash
npm install
cp .env.example .env
npm start
```

打开 <http://localhost:8787>，输入昵称并创建房间。可邀请其他玩家，也可以在房间中开启机器人；最多 8 名玩家与机器人。默认采用 19 块小地图、10 分获胜。地图和胜利目标可由房主调整。

创建时可选择「一起开拓」或「AI 观战」。AI 观战模式支持 2–8 位 AI 自动对战，房主与来访者均以观战者身份观看，不占玩家席位；刷新可恢复观战房主身份。所有人离开 10 分钟后，房间与后台对局会被清理。

新服务器监听 `0.0.0.0:52001` 的文件传输、AI 配置与 systemd 步骤见 [DEPLOY.md](DEPLOY.md)。服务也支持 `HOST`、`PORT` 环境变量，例如 `HOST=0.0.0.0 PORT=52001 npm start`。

当前房间和对局只保存在服务器内存中；重启服务会清空正在进行的游戏。5–8 人模式沿用本项目的普通轮流回合，不包含实体扩展版的特殊建造阶段。

## 玩法

- 初始摆放按正序、倒序进行；每人摆两个定居点和两条相邻道路。第二个定居点领取周围资源。
- 掷骰后产出资源；7 点触发弃牌、移动强盗和抢牌。棋盘高亮处可直接点击建造。
- 可按资源数量向指定玩家提出多种资源交换，受邀玩家可接受或拒绝；机器人必定响应。也可直接与银行或港口交易。
- AI 主动发出的交易会等待回复；30 秒未完成则自动撤回。延迟返回的模型结果不会用于已经更换的交易提案。
- 银行每种资源各有 29 张。港口对称连接同一条海岸边的两个顶点，提供 3:1 或指定资源 2:1 交易。
- 地图轮廓及港口锚点对齐参考站：小地图 19 块／9 港口，中地图 30 块／11 港口，大地图 37 块／12 港口。港位固定，资源地形、数字与港口类型随机；码头朝向由相邻海格决定。
- 另有两种自定义超大地图：超大大陆 61 块／18 港口，双岛地峡 73 块／20 港口，建议 6–8 人。双岛由中央陆地通道连接，可沿现有规则修建道路；每种资源仍为 29 张。
- 强盗移动会播放约 0.76 秒的弧线过渡及落点提示，玩家和观战者都可见；系统开启“减少动态效果”时直接显示落点。
- 每人最多 15 条道路、5 个定居点、4 座城市。每回合至多打出一张非胜利点发展卡，新买的卡要等下回合才能打出。
- 可在本页右上角打开「玩法」查看费用和得分方式。
- 自己的五种资源与发展卡固定显示在手牌区；建造费用在操作按钮下方显示。
- 手机端支持双指缩放、放大后拖动，以及「＋／−／全岛」按钮。点选建造位置后先预览，再确认，避免误触消耗资源。
- 手机竖屏手牌与操作栏固定在底部；横屏移至右侧。点击「玩家与动态」打开玩家、库存和日志面板。
- 交易数量通过加减按钮选择，弃牌通过点选卡片完成。发展卡说明会显示暂不可用的具体原因。
- 刷新页面可恢复原席位和房主身份；同一席位在新页面打开时，旧连接会退出。准备阶段断线席位保留 45 秒。
- 抢牌日志不公开资源种类；银行不足的结算、最长路并列和自己的回合获胜遵循基础规则，每种资源 29 张为本项目设定。

## AI 模式

AI 难度默认「大模型」，也可以选择「基础规则」。策略目录由服务端 `/api/bot-profiles` 提供；在 `bots/profiles.js` 中注册新策略即可扩展难度。每个策略实现 `decide({ state, config, fallback, onFallback })`，返回动作或动作 Promise；`state` 只包含当前 AI 有权查看的信息，`config` 仅在服务端使用。公开目录只返回标识、名称和说明。

「规则 Bot」不调用外部模型。选择「AI Bot」后，服务端自动读取项目根目录的 `.env`；把 `.env.example` 复制为 `.env` 后，填写 `CATAN_AI_BASE_URL`、`CATAN_AI_MODEL`、`CATAN_AI_KEY`，网页不需要配置。也可以直接设置同名环境变量，环境变量优先。模型超时、请求失败或返回无效动作时，规则 Bot 会接手，原因显示在游戏日志中。`.env` 已列入 `.gitignore`，请勿提交或分享真实密钥。

## 测试

```bash
npm test
```

自动测试覆盖双人联机与 AI 回退、密码与观战权限、刷新恢复席位、资源短缺、抢牌隐私、发展卡、最长路并列、胜利时机、多人交易。另有 2/3/4/6/8 人完整对局模拟，对每次动作检查资源守恒与建筑上限。测试使用本地模拟模型服务，不需要真实 API Key。

```bash
npm run test:ui
```

浏览器回归会自动启动独立测试服务与无头 Chrome，执行三人开局、棋盘点击、报价响应、页面刷新，以及手机点选确认、交易加减、发展卡与弃牌界面。覆盖 1440、768、390、320 像素宽度和手机横屏，截图保存在 `artifacts/ui/`。macOS 会自动寻找 Google Chrome；其他环境可通过 `CHROME_BIN` 指定 Chrome / Chromium 路径。

手机开局、弃牌与交易操作使用触摸事件测试，并验证双指缩放中点跟随、单指拖动、手势后继续点选，以及 320×568 小屏操作。完整对局模拟使用服务器共享的机器人调度器，覆盖当前 AI 等待其他玩家弃牌的情况。

资源插画位于 `public/assets/`，由同一组 SVG 在棋盘、手牌、银行和交易界面复用，避免不同设备的 Emoji 字形差异。

基础规则参考 [CATAN 官方规则](https://www.catan.com/understand-catan/game-rules)。
